Client Journey Playbook

고객을 만나고, 홈페이지를 완성하기까지

4단계로 나눈 전체 여정입니다. 각 단계를 열면 실제 프롬프트·코드·체크리스트가 나옵니다. 진행 상태는 이 브라우저에 자동 저장됩니다.

Stage A

배우고 준비해야 하는 단계

환경 세팅, 클로드 코딩 실습, AI 이미지 생성, 레퍼런스 리서치, 샘플 홈페이지 제작까지 — 첫 문의가 오기 전에 갖춰야 할 실력과 자료.
Stage B

고객 만나는 단계

타겟 좁히기, 거절 못하는 오퍼 설계, DM·제안 스크립트, 거절 대응, 7일 액션 플랜 — 첫 계약을 만들기 위한 실전 영업 루틴.
Stage C

고객 만나면 해야하는 단계

첫 상담, 설문·진단·비교분석, 사이트맵 기획, 제안서·견적서 작성, 계약 체결까지 — 문의를 계약으로 만드는 과정.
Stage D

계약이 성사되면 해야하는 단계

페이지 설계, 시안 제작, 피드백 반영, 제작, 점검, 배포, 인수인계, 사후관리까지 — 계약 이후 실제 완성까지의 전 과정.
각 단계 안의 프롬프트·코드는 복사 버튼으로 바로 복사할 수 있고, 원 안을 클릭하면 미완료 → 진행중 → 완료 순으로 상태가 바뀝니다 (진행중은 주황, 완료는 초록). "내 자료 / 메모" 칸에 적은 내용도 자동 저장됩니다. "전광판" 표시가 붙은 단계는 이미 만든 도구(진단·비교분석·기획·정보·페이지상세·견적서·시안·인수인계)와 바로 연결됩니다.
