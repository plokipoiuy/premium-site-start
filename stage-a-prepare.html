Claude Code 작업 환경 세팅 ⌄

Claude Code로 아임웹·식스샵 코드위젯 작업을 하기 전에, 스킬과 CLAUDE.md를 먼저 세팅해야 강의와 같은 결과물이 나옵니다. 아래 두 방법 중 하나를 고르세요.

방법 1 — 원클릭 설치 키트 (Mac, 권장)

  1. claude-setup-kit.zip 다운로드 후 압축 해제
  2. 폴더 안의 설치하기.command 를 우클릭 → 열기 → 열기 ("확인되지 않은 개발자" 경고가 떠도 정상) → 스킬 6종 자동 설치
  3. 폴더 안의 CLAUDE.md 를 작업할 프로젝트 폴더 최상위에 복사 ⭐
  4. Claude Code 대화창에서 ui-ux-pro-max 플러그인 1개만 추가 설치 (아래 명령 참고) 후 /plugin 메뉴에서 선택 설치
  5. claude.ai 설정 → 커넥터에서 Figma, Adobe Express, lazyweb 연결

방법 2 — 웹 버전 (claude.ai/code), 설치 아예 필요 없음

  1. github.com 가입/로그인
  2. 스타터 저장소 haesam/premium-site-start (CLAUDE.md + 디자인 스킬 6종이 이미 들어있음) 페이지에서 Use this template → Create a new repository 클릭 (버튼이 안 보이면 우측 상단 Fork) → 본인 계정으로 복사
  3. claude.ai/code 접속 → 처음이면 GitHub 연결 승인(Authorize) → 방금 복사한 저장소 선택 → 세션 시작
  4. 바로 요청: "포트폴리오 사이트 만들어줘" → 스킬·CLAUDE.md 설치 단계가 전부 생략됨
  5. ui-ux-pro-max 플러그인은 세션 대화창에서 마켓플레이스 명령 입력, 커넥터(Figma 등)는 claude.ai 설정에서 동일하게 연결
데스크톱(로컬)에서 작업하는 사람도 이 저장소를 git clone 하거나 GitHub에서 ZIP으로 받으면, 키트 없이 같은 세팅으로 바로 시작할 수 있습니다.

0. 사전 준비물

  • Claude 유료 계정 (Pro 이상)
  • Claude Code 설치 — 데스크톱 앱 또는 터미널에서 npm install -g @anthropic-ai/claude-code
  • Node.js 설치 (nodejs.org — LTS 버전)
  • Git 설치 (Mac은 기본 포함, 터미널에서 git --version으로 확인)

커넥터 연결 (claude.ai 설정)

스킬이 아니라 claude.ai의 설정 → 커넥터에서 각자 계정으로 연결하는 항목입니다.

  • Figma — 디자인 ↔ 코드 양방향 변환
  • Adobe Express — 포스터/SNS 그래픽 등 시각 디자인 제작
  • lazyweb — 실제 서비스 UI 레퍼런스 검색, 목업 생성
  • (선택) 사용 중인 웹사이트 빌더, AI 이미지/영상 생성 커넥터

설치가 끝나면 Claude Code를 열고 아래처럼 물어봐서 확인합니다. 3d-scroll-website, remotion-best-practices, find-skills, frontend-design, theme-factory, webapp-testing, ui-ux-pro-max 가 전부 보이면 세팅 완료입니다.

클로드 코딩 실습 ① 플로팅 액션 버튼(FAB) ⌄

고객요청 중 가장 많은 요청 중 하나가 화면에 둥둥 떠다니는 플로팅 액션 버튼(FAB)입니다. FAB는 코드 위젯에 붙이는 것이 아니라, 아래 3가지를 준비해서 진행합니다: ① 아이콘 이미지 ② 링크(예: 카카오채널 링크) ③ 플로팅 버튼 코드.

  1. STEP1) 아래 코드를 복사합니다.
  2. STEP2) 복사한 코드를 [환경설정 > SEO(검색엔진최적화) > Footer Code]에 붙여넣기 합니다.
  3. STEP3) 이 코드를 클로드에도 붙여넣고 "프리뷰를 보여줘"라고 요청합니다. 아이콘이 표시가 안 되면 "아이콘까지 보여줘"라고 한 번 더 말해주세요.
  4. STEP4) 이후로는 클로드와 자유롭게 작업합니다. 텍스트나 아이콘 변경을 요청하면 클로드가 알아서 바꿔줍니다. 클로드가 잘 못 알아들으면 이렇게 다시 알려주세요: "아임웹은 html코드창에 html, css, javascript를 모두 하나의 코드로 넣어야 해. 그리고 header는 별도로 세팅이 되어있기 때문에 header는 빼고 코드를 작성해야해."

function openTab(evt, tabName) {
    var i, tabContent, tabBtns;
    
    tabContent = document.getElementsByClassName("tab-content");
    for (i = 0; i < tabContent.length; i++) {
        tabContent[i].classList.remove("active");
    }
    
    tabBtns = document.getElementsByClassName("tab-btn");
    for (i = 0; i < tabBtns.length; i++) {
        tabBtns[i].classList.remove("active");
    }
    
    document.getElementById(tabName).classList.add("active");
    evt.currentTarget.classList.add("active");
}
</script>

// 카운터 애니메이션 함수
function animateCounter(element, start, end, duration) {
    let startTimestamp = null;
    const step = (timestamp) => {
        if (!startTimestamp) startTimestamp = timestamp;
        const progress = Math.min((timestamp - startTimestamp) / duration, 1);
        
        // 소수점이 있는 숫자인지 확인
        const hasDecimal = end % 1 !== 0;
        const current = progress * (end - start) + start;
        
        if (hasDecimal) {
            element.textContent = current.toFixed(1);
        } else {
            element.textContent = Math.floor(current).toLocaleString();
        }
        
        if (progress < 1) {
            window.requestAnimationFrame(step);
        }
    };
    window.requestAnimationFrame(step);
}

// Intersection Observer로 뷰포트 진입 감지
const observerOptions = {
    threshold: 0.5
};

const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            const counters = entry.target.querySelectorAll('.counter-number');
            counters.forEach(counter => {
                const target = parseFloat(counter.getAttribute('data-target'));
                animateCounter(counter, 0, target, 2000);
            });
            observer.unobserve(entry.target);
        }
    });
}, observerOptions);

// 페이지 로드 시 관찰 시작
document.addEventListener('DOMContentLoaded', () => {
    const counterSection = document.querySelector('.counter-section');
    if (counterSection) {
        observer.observe(counterSection);
    }
});

만능 클로드 코딩 명령법 (프롬프트 템플릿) ⌄

클로드에게 코드위젯 작업을 명령할 때 매번 결과물 품질이 들쭉날쭉하지 않도록, 아래 4요소와 프롬프트 양식을 그대로 따라 쓰세요.

클로드 코딩 명령에 들어갈 요소 4가지

  1. 용도 : 아임웹 코드위젯용 코드
  2. 기능 : 구현하고 싶은 기능
  3. 옵션 : 색상, 텍스트 내용 등 수정 가능한 요소
  4. 조건 : 필수조건, 제외조건 등

클로드 프롬프트에 명령하는 법

  1. "참고 코드"와 "새로운 요청" 구분 명확히 하기 — ===== 구분선으로 분리해서 기존 코드와 수정 요청을 헷갈리지 않게 합니다
  2. 코드 용도 언급하기 — "이 코드는 ~하는 코드야"라고 정확히 알려줍니다
  3. 주의사항 말하기 — 아임웹에서 꼭 지켜야 할 것들을 명시합니다
  4. 원하는 기능 구체적으로 말하기 — 변경할 대상은 큰따옴표("이렇게")로 감싸서 명확하게 지정합니다 (예: "카톡채널링크"를 "인스타그램"으로 바꿔줘)

아임웹 코딩 필수 프롬프트 명령

  • 첫 대화 시작할 때 (딱 1번만!) — "header 를 절대 넣어선 안돼, body 에 넣을 코드만 만들어줘"
  • 매번 포함해야 할 명령 — ① 용도 명시(예: 카운트업이 되는 코드야) ② 구체적인 기능(원하는 동작 자세히 설명)

(function () {
  /* ======================================================
     [ 메인 타이틀 애니메이션 설정 ]
  ====================================================== */

  // 최대 확대 배율 (예: 22 = 22배까지 커짐)
  var BSTS_MAX_SCALE   = 22;

  // 사라지기 시작하는 스크롤 시점 (0.0 ~ 1.0)
  var BSTS_FADE_START  = 0.55;

  // 완전히 사라지는 스크롤 시점 (FADE_START보다 커야 함)
  var BSTS_FADE_END    = 0.88;

  // 블러 시작 시점 (0.0 ~ 1.0)
  var BSTS_BLUR_START  = 0.2;

  // 블러 최대값 (px) — 클수록 더 흐려짐
  var BSTS_BLUR_MAX    = 30;

  /* ======================================================
     [ 서브텍스트 애니메이션 설정 ]
  ====================================================== */

  // 서브텍스트 최대 확대 배율 (메인보다 작으면 시차감)
  var BSTS_SUB_MAX_SCALE   = 14;

  // 서브텍스트 확대 시작 시점 (메인보다 살짝 늦게)
  var BSTS_SUB_SCALE_START = 0.05;

  // 서브텍스트 사라지기 시작 시점
  var BSTS_SUB_FADE_START  = 0.45;

  // 서브텍스트 완전히 사라지는 시점
  var BSTS_SUB_FADE_END    = 0.75;

  // 서브텍스트 블러 시작 시점
  var BSTS_SUB_BLUR_START  = 0.15;

  // 서브텍스트 블러 최대값 (px)
  var BSTS_SUB_BLUR_MAX    = 20;

  /* ====================================================== */

  var trigger  = document.getElementById('brand-textscroll-trigger');
  var wrap     = document.getElementById('brand-textscroll-wrap');
  var titleEl  = document.getElementById('brand-textscroll-title');
  var subEl    = document.getElementById('brand-textscroll-subtitle');

  function bstsLerp(a, b, t) {
    t = t < 0 ? 0 : t > 1 ? 1 : t;
    return a + (b - a) * t;
  }

  function bstsOnScroll() {
    var rect     = trigger.getBoundingClientRect();
    var total    = trigger.offsetHeight - window.innerHeight;
    var scrolled = -rect.top;
    var progress = scrolled / total;
    progress = progress < 0 ? 0 : progress > 1 ? 1 : progress;

    // 트리거 영역 안에서만 표시
    var inView = rect.bottom > 0 && rect.top < window.innerHeight;
    wrap.style.visibility = inView ? 'visible' : 'hidden';

    /* ── 메인 타이틀 ── */
    var scale = bstsLerp(1, BSTS_MAX_SCALE, progress);

    var opacity = 1;
    if (progress > BSTS_FADE_START) {
      opacity = bstsLerp(1, 0, (progress - BSTS_FADE_START) / (BSTS_FADE_END - BSTS_FADE_START));
    }

    var blur = 0;
    if (progress > BSTS_BLUR_START) {
      blur = bstsLerp(0, BSTS_BLUR_MAX, (progress - BSTS_BLUR_START) / (1 - BSTS_BLUR_START));
    }

    titleEl.style.transform = 'translate(-50%, -50%) scale(' + scale + ')';
    titleEl.style.opacity   = opacity;
    titleEl.style.filter    = 'blur(' + blur + 'px)';

    /* ── 서브텍스트 ── */
    var subP = (progress - BSTS_SUB_SCALE_START) / (1 - BSTS_SUB_SCALE_START);
    subP = subP < 0 ? 0 : subP > 1 ? 1 : subP;
    var subScale = bstsLerp(1, BSTS_SUB_MAX_SCALE, subP);

    var subOpacity = 1;
    if (progress > BSTS_SUB_FADE_START) {
      subOpacity = bstsLerp(1, 0, (progress - BSTS_SUB_FADE_START) / (BSTS_SUB_FADE_END - BSTS_SUB_FADE_START));
    }

    var subBlur = 0;
    if (progress > BSTS_SUB_BLUR_START) {
      subBlur = bstsLerp(0, BSTS_SUB_BLUR_MAX, (progress - BSTS_SUB_BLUR_START) / (1 - BSTS_SUB_BLUR_START));
    }

    subEl.style.transform = 'translate(-50%, -50%) scale(' + subScale + ')';
    subEl.style.opacity   = subOpacity;
    subEl.style.filter    = 'blur(' + subBlur + 'px)';
  }

  window.addEventListener('scroll', bstsOnScroll, { passive: true });
  bstsOnScroll(); // 초기 실행
}());

  5. AI에 사용

motionsites.ai × 식스샵 프로 MCP로 3D 애니메이션 섹션 넣기 ⌄

motionsites.ai에서 프리미엄 애니메이션·3D 섹션 프롬프트를 복사한 뒤, Claude Code에서 식스샵 프로용 코드로 변환하고, 식스샵 프로 MCP로 바로 반영하는 6단계 과정입니다. 별도 배포(Vercel/GitHub) 없이 끝납니다. 필요한 것: motionsites.ai 무료 계정 · Claude Code(무료 티어로 충분) · 식스샵 프로 계정(MCP는 무료 플랜까지 개방).

STEP내용
01 · motionsites.ai란흔한 레이아웃·스톡 이미지 대신, 프리미엄 애니메이션·3D 웹사이트용 완성 프롬프트 라이브러리. Sites(완성 페이지) / Sections(개별 컴포넌트, 가장 흔히 씀) / Backgrounds(독립 배경) 3가지 섹션으로 구성. 무료 템플릿은 Copy 버튼으로 프롬프트를 바로 복사 가능
02 · 템플릿 고르고 프롬프트 복사상단 내비게이션 "Sections" 클릭 → Pricing 필터에서 Free 선택 → 템플릿 클릭해 미리보기(톤이 맞는지, 모바일에서도 무난한지 확인) → Copy 클릭 → 메모 앱에 안전하게 붙여넣기. 15분 넘게 고르지 말고 80%만 맞아도 진행

05 · 바이브 코딩으로 다듬고 고치기깨진 섹션은 스크린샷 첨부 후 "프롬프트 03 · 수정"으로 요청. 간단한 미세 수정(버튼 색상, 간격)은 식스샵 에디터 안 블록 AI에게 자연어로 바로 지시. 모션 추가·모바일 반응형도 각각 전용 프롬프트로 요청하고, 반영 전 모바일을 꼭 확인
06 · 식스샵 프로 MCP로 반영 + 도메인 연결claude.ai 커넥터 설정에서 식스샵 프로 MCP 연결 → "프롬프트 04 · 반영"으로 블록을 만들어 페이지에 삽입 요청 → 관리자/미리보기 링크로 확인 → 게시 요청. 도메인은 식스샵 프로 관리자 → 도메인 메뉴에서 구매·연결(선택)

파스비코나 구조로 서비스 소개자료 준비 ⌄

설득형 상세페이지·세일즈 콘텐츠의 핵심 프레임워크인 파스비코나(PASBICONA) 구조로, 내 서비스 소개자료를 준비하는 단계입니다. 팔리는 페이지에는 구조가 있습니다 — 감정 → 공감 → 해결 → 신뢰 → 행동의 단계로 설계해야 합니다.

파스비코나 9단계 개요

단계의미역할
P – Problem (문제)고객의 문제는 무엇인가?공감 시작, 불편함 인식
A – Affinity (공감)나도 같은 경험이 있는가?관계·신뢰 형성
S – Solution (해결)어떤 해결책을 제시하는가?명확한 제안
B – Benefit (이익)고객은 어떤 변화를 얻게 되는가?결과·가치 강조
E – Evidence (증거)그 결과는 증명 가능한가?후기·사례·데이터
C – Contents (구성)무엇을, 어떻게 제공하나?프로그램·커리큘럼·서비스 내용
O – Offer (제안)지금 선택해야 하는 이유는?혜택·한정성·보너스
N – Narrow (대상 한정)누구에게 맞고, 맞지 않는가?타깃 명확화
A – Action (행동 유도)지금 무엇을 해야 하는가?CTA 버튼, 신청 안내

구조 흐름 요약

공감 → 연결 → 해결 → 결과 → 증거 → 구성 → 제안 → 한정 → 행동

  • 상단 (P~S): 문제·공감·해결의 감정선
  • 중단 (B~C): 가치·증거·구성의 신뢰선
  • 하단 (O~A): 제안·한정·행동의 전환선

상세페이지 적용 예시

  • Hero 구간 → Problem: 예: "홈페이지를 만들어도 문의가 오지 않나요?"
  • 스토리 구간 → Affinity + Solution: 예: "저도 같은 문제를 겪었지만, 구조를 바꾸자 달라졌어요."
  • 본문 구간 → Benefit + Evidence + Contents: 예: "3단계 템플릿으로 전환율이 3배 상승했습니다."
  • 제안 구간 → Offer + Narrow: 예: "이번 기수 10명 한정, 브랜딩 관심 있는 분만 신청"
  • CTA 구간 → Action: 예: "지금 무료 상담 신청하기 →"

활용 영역

상세페이지 기획 / 서비스 제안서·강의 소개문 / 이메일 마케팅·SNS 콘텐츠 / 세일즈 웨비나·랜딩페이지 설계

실습 과제

  1. 내 고객의 가장 큰 문제(P) 한 줄로 쓰기
  2. 나의 경험 중 공감되는 사례(A) 정리
  3. 내가 제시할 해결 솔루션(S) 한 문장 완성
  4. PAS 세 문장으로 시작문단 구성
핵심 메시지: "팔리는 페이지는 문장보다 흐름이 중요하다. 파스비코나는 그 흐름을 시각적으로 정리해주는 설계지도다."
