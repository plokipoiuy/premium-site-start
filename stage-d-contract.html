페이지별 상세 설계 ⌄

확정된 사이트맵을 바탕으로, 제작할 페이지 목록과 각 페이지에 필요한 구성요소·기능을 페이지 단위로 정의합니다. 이 단계는 별도의 강의 프롬프트 없이, 앞서 정리한 기획 내용을 페이지별로 나눠 정리하면 됩니다.

전광판 05 · 페이지 상세
홈페이지 기획~점검 4단계 개요 ⌄

실제 제작에 들어가기 전, 전체 흐름을 4단계로 다시 정리하면 다음과 같습니다.

1. 기획 (Planning)

  • 목표 설정: 홈페이지로 이루고 싶은 핵심 목표 정의 (예: 상담예약, 강의문의)
  • 타깃 정의: 방문자(고객)의 특징과 니즈 파악
  • 콘텐츠 구성: 어떤 정보와 자료를 제공할지 결정
  • 사이트맵 설계: 메뉴와 페이지 흐름 정리

2. 설계 (Designing)

  • 와이어프레임 제작: 페이지별 기본 구조(레이아웃) 구상
  • UI/UX 설계: 방문자가 쉽게 탐색하고 행동하도록 설계
  • 브랜드 톤 반영: 색상, 폰트, 이미지 스타일 등 일관된 디자인 요소 적용

3. 제작 (Building)

  • 콘텐츠 제작: 텍스트, 이미지, 영상, 후기, 자료 등 준비
  • 웹빌더 활용: 아임웹, 식스샵 등 노코드 툴을 사용해 실제 페이지 구현
  • 기능 구현: 문의 폼, 결제, 캘린더, 뉴스레터 구독 등 필요한 기능 추가

4. 점검 (Testing)

  • 기능 테스트: 링크, 버튼, 폼, 결제 등이 정상 작동하는지 확인
  • 디바이스/브라우저 호환성: PC/모바일/태블릿에서 화면 확인
  • SEO 및 성능 최적화: 검색엔진 노출 확인
  • 피드백 반영: 사용자 테스트 후 수정 보완

전광판 07·08 · 시안 미리보기
고객 피드백 반영 ⌄

준비한 시안 중 하나를 고객에게 선택받고, 수정 요청 사항을 정리해서 실제 제작에 반영할 준비를 합니다.

실제 제작: 만능 클로드 코딩 명령법 실전 적용 ⌄

실제 제작 단계에서 매번 새로 고민하지 말고, 아래 기본 양식에 채워 넣어 클로드에게 요청하세요. 두 가지 실전 예시는 Stage A의 6단계를 참고하세요.

코드 요청 프롬프트 양식 (Stage A·a6 참고)
[ 참고 코드 ]
(기존 코드가 있다면 여기에 붙여넣기)

======

[ 코드 용도 언급 ]
이 코드는 ~ 하는 코드야

[ 주의사항 언급 ]
header 를 절대 넣어선 안돼, body 에 넣을 코드만 만들어줘

[ 구체적인 기능 명령 ]
여기에 원하는 기능 자세히 작성!
변경할 텍스트나 요소는 "큰따옴표"로 감싸서 명확하게 지정하기
최종 점검 ⌄

배포 전 아래 항목을 순서대로 점검하세요.

  • 기능 테스트: 링크, 버튼, 폼, 결제 등이 정상 작동하는지 확인
  • 디바이스/브라우저 호환성: PC/모바일/태블릿에서 화면 확인
  • SEO 및 성능 최적화: 검색엔진 노출 확인
  • 피드백 반영: 사용자 테스트 후 수정 보완
배포 ⌄

배포 방법은 웹빌더/스택에 따라 다릅니다. 두 가지 대표 경로는 다음과 같습니다.

1. Vercel

도메인을 연결한 후 게시하면 끝입니다.

2. 식스샵 프로 — MCP로 바로 반영

식스샵 프로는 MCP(Model Context Protocol)를 무료 플랜까지 개방해놓았습니다. Claude에 식스샵 프로 MCP를 연결해두면, GitHub이나 Vercel 없이도 만든 코드를 바로 내 홈페이지에 반영할 수 있습니다.

반영 과정

  1. Claude에 식스샵 프로 MCP 연결 — Claude의 커넥터 설정에서 식스샵 프로를 연결하면, 내 식스샵 계정의 테마·페이지·섹션을 Claude가 직접 조회하고 수정할 수 있게 됩니다.
  2. 만든 코드를 블록으로 등록 — "이 코드로 블록을 만들어서 [페이지명] 상단에 넣어줘" 라고 요청하면 Claude가 직접 블록 컴포넌트를 만들고 원하는 섹션에 삽입합니다.
  3. 미리보기 확인 — 식스샵 관리자 화면이나 미리보기 링크로 실제 적용 모습을 확인하세요.
  4. 게시(발행) — 만족스러우면 Claude에게 사이트를 게시해달라고 요청하면, 식스샵 프로 관리자에서 별도의 배포 과정 없이 바로 반영됩니다.
식스샵 반영용 프롬프트(모바일 반응형 고치기 등)는 Stage A·10단계의 "프롬프트 04 · 반영"을 참고하세요.
인수인계 ⌄

도메인, 호스팅, 관리자 계정 정보, 기본 사용법을 정리해서 고객에게 전달합니다. 이 단계는 별도의 강의 프롬프트 없이, "전광판" 도구의 인수인계 섹션에 직접 정리해서 입력하면 됩니다.

전광판 09 · 인수인계 정보
고객 응대 상황별 멘트집 (18종) ⌄

다양한 상황에서 고객에게 실제로 써먹을 수 있는 멘트를 모았습니다. 아직 경험이 없는 분들도 언젠가는 이런 상황을 마주하게 됩니다. 미리 숙지해두고 당황스러운 순간에 자연스럽게 대처하세요.

1. 더 비싼 상품 구매를 유도하고 싶을 때
"기본 상품도 물론 훌륭하지만, 조금만 더 투자하시면 이러한 추가 기능이 포함된 이 상품을 선택하실 수 있습니다. 어차피 언젠가는 필요한 옵션입니다. 고객님의 비즈니스에 특히 더 적합한 선택지가 되실 겁니다. 어떤가요?"
2. 비싸다고 느끼는 고객에게 저렴한 다른 서비스 대신 내 서비스를 선택하도록 권할 때
"싸면 그만한 이유가 다 있다는 것 알고 계시죠? 저희는 무조건 저렴한 가격보다는 장기적인 퀄리티와 효과를 중요하게 생각하고 있습니다. 한번 서비스를 시작하시면 유지보수나 추가 지원에서 품질 차이를 느끼실 수 있을 거예요. 품질을 고려하신다면 저희 서비스가 더 적합하실 겁니다."
3. 서비스 결과물이 마음에 드는지 확인하고 싶을 때
"저희가 함께 만들어낸 결과물이 고객님이 원하셨던 방향과 잘 맞는지 궁금합니다. 혹시 더 기대하시는 부분이 있으시면 언제든 말씀해 주세요."
4. 결제를 미루는 고객에게 지금 결제하도록 권할 때
"지금 결제하시면 바로 작업을 시작할 수 있어서 결과물을 더 빠르게 받으실 수 있습니다. 결제에 대해 궁금하신 점이 있으시면 말씀해 주세요!"
5. 수정 요청이 지나치게 많을 때 추가 수정은 어렵다고 전달할 때
"앞서 협의한 범위에서 최선을 다해 수정해드렸습니다. 더 이상의 수정은 추가 비용이 발생할 뿐 아니라 일정이 계속 미뤄질 수 있습니다. 오히려 수정이 많아지면 기획에서 벗어날 수 있어 오히려 엉뚱한 방향으로 갈 여지가 있습니다. 현 상태에서 고객들의 피드백도 받아봐야 수고를 더실 수 있으니 지금 상태에서 최상의 결과물을 제공할 수 있도록 마무리해 보시고 추후 수정이 꼭 필요한 경우 다시 논의 해보시면 어떨까요?"
6. 월 단위 유지보수를 장기 계약으로 유도하고 싶을 때
"단기적으로 진행하는 것도 가능하지만, 장기 계약을 선택하시면 일정 부분 할인이 적용될 뿐만 아니라 저희가 고객님의 비즈니스를 더 깊이 이해하고 최적의 솔루션을 제공할 수 있는 시간이 생깁니다. 장기적인 관점에서 안정적인 관리를 원하신다면 장기 계약이 더 유리하실 거예요."
7. 고객이 스스로 원하는 것을 모를 때, 레퍼런스를 찾아오도록 유도할 때
"고객님의 취향을 좀 더 파악하기 위해 마음에 드는 사이트나 디자인 레퍼런스를 몇 가지 찾아보시면 좋을 것 같아요. 그런 예시를 참고하면 저희가 더 고객님의 스타일에 맞춘 제안을 드리기 쉬울 것 같습니다."
8. 홈페이지 자료를 보내줘야 하는 고객이 자료 발송을 미루어 일정 차질이 생길 때
"준비하신 자료를 최대한 빨리 보내주시면, 저희도 약속드린 일정에 맞춰 작업을 진행할 수 있을 것 같아요. 협의된 일정 이후에는 다른 프로젝트가 대기중에 있어 더 미뤄질 경우 불가피하게 추가비용이 발생할 수 있습니다. 혹시 자료 준비에 어려움이 있으시면 말씀해 주세요. 도와드릴 수 있는 부분이 있으면 최대한 지원하겠습니다."
9. 견적을 제시할 때 비싸게 느끼지 않게 말하고 싶을 때
"저희가 제시드리는 금액은 고객님의 요구사항에 맞춘 최적의 결과물을 보장하기 위한 범위에서 최소, 최대의 경우에 대해 안내해드린 내용입니다. 한 번에 제대로 하는 것이 가장 저렴하게 진행할 수 있는 방법입니다. 이 금액으로 고객님의 비즈니스에 부합하는 가치와 높은 품질의 결과를 제공해드릴 수 있습니다."
10. 작업이 오래 걸린다는 것을 고객에게 납득시키고 싶을 때
"고객님께서 원하시는 퀄리티를 위해 세부적인 작업이 필요한 부분이 많습니다. 작업이 조금 오래 걸리더라도 그만큼 완성도 높은 결과를 받으시게 될 거예요. 이를 통해 고객님의 비즈니스에도 더 큰 도움이 될 것입니다."
11. 포트폴리오가 없는 상황에서 계약을 제안할 때
"현재 저희가 별도 포트폴리오는 없지만, 그만큼 고객님의 요구에 맞춰 유연하게 작업해드릴 수 있습니다. 만약 결과가 만족스럽지 않으시면 환불을 약속드리니 부담 없이 믿고 맡겨주셔도 좋습니다."
12. 견적만 물어보고 떠날 것 같은 고객에게 경쟁자 대신 나와 거래하도록 유도할 때
"다른 곳도 충분히 살펴보고 비교해보세요. 하지만, 저희는 고객님의 필요에 맞춘 맞춤형 서비스를 제공해드리기 때문에 차별화된 가치를 경험하실 수 있을 거예요. 저희와 함께 하시면 단순한 사이트 제작을 넘어, 고객님의 브랜드를 강화하는 전략적인 파트너가 될 수 있습니다."
13. 결과물이 마음에 들지 않아 환불을 요청하는 고객에게 환불을 해주고 싶지 않을 때
"불만족스러운 사항에 대해 솔직하게 말씀해주셔서 감사드립니다. 해당 부분은 소통에서 문제가 있던 부분이라 충분히 개선할 수 있는 요소로 보입니다. 만족스럽지 않으셨던 부분을 개선할 수 있는 기회를 한 번 더 주신다면, 조금 더 맞춤화된 수정 작업을 통해 기대에 부응할 수 있도록 노력해보겠습니다. 고객님(대표님)도 아예 처음부터 다른 곳에서 하시는 것보다 여기서 조금만 다듬어서 완성시키는 것이 시간 비용 모든 면에서 이득이실 겁니다."
14. 작업이 끝났는데도 결제하지 않는 고객에게 부드럽게 결제를 유도할 때
"작업이 완료되어 결과물을 전달드렸습니다. 혹시 결제와 관련해 궁금한 점이 있으시면 알려주세요. 결제가 완료되면 추가 지원도 빠르게 준비하겠습니다!"
15. 고객에게 긍정적인 후기를 작성하게 하고 싶을 때
"고객님과 함께 멋진 프로젝트를 완성할 수 있어서 저희도 정말 기뻤습니다! 혹시 이번 경험에 대해 간단히 공유해주시면 다른 분들께도 큰 도움이 될 것 같습니다. 좋은 후기를 남겨주시면 정말 감사하겠습니다!"
16. 고객이 지인 소개를 통해 추가 고객을 데려오도록 유도하고 싶을 때
"고객님의 소개로 함께할 수 있는 분들이 계시면 저희가 특별히 준비한 혜택을 제공해드릴 수 있습니다. 고객님의 추천으로 더 많은 분들과 만나게 된다면 정말 기쁠 것 같습니다!"
17. 거절하기 애매한 사소한 요구사항을 자주 부탁하는 고객에게 시간을 빼앗기고 싶지 않을 때
"요청하신 부분에 대해 검토해보았습니다. 현재 진행 중인 프로젝트와 관련된 작업도 큰 것을 먼저 잡지 않으면 작은 것은 다시 손을 대야 하는 경우가 발생합니다. 당연히 일정 비용 모두 늘어나게 될 것입니다. 해서 크고 중요한 요소둘에 우선순위로 집중하기 위해 작은 추가 요청에 대해서는 반영이 어려울 수 있습니다. 중요한 작업을 우선적으로 마무리하는 데에 집중하는 것이 고객님의 결과물에도 더 도움이 될 것 같습니다."
18. 질문만 하고 결정을 미루는 고객에게 빠르게 결정을 내리도록 유도할 때
"이제 프로젝트 시작 여부를 결정해주시면 바로 작업에 착수할 수 있습니다. 궁금한 점이 더 있으시다면 언제든 알려주세요. 빠르게 결정해주시면 최상의 서비스로 보답하겠습니다!"
프리미엄 포지셔닝과 단가 로드맵 ⌄

포트폴리오 기간이 끝난 뒤에는 가격을 어떻게 올려나갈지 미리 그려두세요.

Dan Kennedy: "경쟁하기 위해 가격을 낮추는 순간 패배한 것이다."

프리미엄 포지셔닝 5기둥

기둥첫 고객 단계 적용법
1. 독점성"[업종] 전용 홈페이지" 업종 실전 노하우 강조
2. 권위AI 제작 능력 + 샘플의 높은 완성도 선제공
3. 결과 중심"홈페이지" 안 말하고 "예약 자동화", "문의 누락 방지" 로 말하기
4. 전문적 프레젠테이션상담용 1페이지 제안서 + 목업 이미지 3장
5. 프리미엄 가격모두가 저렴하면 품질 의심 받음. "50만원이면 부담이 없지" 도 맞지만, "150만원인 이유가 있어요"가 더 강함

재계약 및 소통 팁 ⌄

프로젝트가 계약 범위를 벗어나거나 중요한 내용을 전달할 때 참고할 팁입니다.

재계약: 지나친 요구사항 혹은 기간 연장으로 인해 과도한 추가 작업 및 일정이 발생할 경우, 기존 계약의 범위를 벗어난 현 상황에 대해 클라이언트에게 충분히 이해시킨 후 잔금 처리를 요청하고 첫 계약을 종료합니다. 그리고 남은 내용에 대한 추가 계약을 진행하는 것이 좋습니다.
소통: 이 내용은 못 봤다 하는 상황을 방지하기 위해 서면으로만 전달하기 보다는 중요한 내용에 대해서는 구두 혹은 라이브로 직접 안내해주는 것이 좋습니다.
다음 고객으로: 내 가치를 높이는 활동 ⌄

프로젝트 하나가 끝났다고 멈추지 마세요. 아래 활동들을 꾸준히 이어가면 다음 고객이 더 쉽게 찾아오는 선순환이 만들어집니다.

  1. 웨비나(Webinar)를 통한 전문성 강화
    • 주제 선정: 고객이 자주 묻는 질문이나 어려움을 해결하는 내용 (예: "노코딩으로 빠르게 성공적인 홈페이지 제작하기")
    • 구성: 문제점 정의 → 솔루션 제안 → 직접 시연 → 성공 사례 공유 → Q&A
    • 활용 팁: 녹화본을 유튜브·홈페이지에 재활용, 참여자에게 무료 체크리스트·PDF 가이드로 팔로업
  2. 무료 자료 배포
    • 자료 유형: "홈페이지 제작을 위한 체크리스트" / "Imweb 노코딩 기능 활용 가이드북" 등
    • 목적: 잠재 고객의 관심을 끌고 이메일 리스트 확보, "이 사람은 믿을 만하다"는 신뢰 형성
    • 배포 방법: 이메일 구독, 블로그 글, SNS 게시물
  3. 사례 중심 콘텐츠 제작
    • 방법: 과거 프로젝트 성공 사례 활용 (예: "5주 만에 소규모 카페 웹사이트를 런칭한 이야기")
    • 활용 매체: 블로그, 유튜브, 인스타그램 스토리 — 고객 리뷰와 Before/After 이미지 활용
    • 효과: 고객이 나와 협업하면 얻을 수 있는 결과를 상상하도록 유도
  4. 커뮤니티 활동
    • 전략: 전문성 중심의 커뮤니티 형성 (예: "노코딩 웹사이트 제작자 네트워크" 카카오톡/디스코드 그룹)
    • 목표: 무료 Q&A 세션으로 전문성을 보여주고, 장기적으로 유료 서비스 전환
  5. SNS와 브랜딩 강화
    • 일상 속 '팁' 제공, 비하인드 스토리, 투표·질문 응답·라이브 방송 등 인터랙티브 콘텐츠
    • 효과: 팔로워와의 지속적인 관계 형성, 전문성 있는 사람이라는 인식
  6. 무료 컨설팅 또는 샘플 작업 제공
    • 15~30분 무료 컨설팅 세션, 샘플 페이지/와이어프레임 초안 무료 제공
    • 주의점: 컨설팅에서 유료 서비스의 필요성을 자연스럽게 언급해 전환율 관리
  7. 소규모 워크숍/교육 프로그램 운영
    • 예: "Imweb으로 만드는 첫 홈페이지 워크숍" / "디자인 초보자를 위한 웹사이트 제작 1일 클래스"
    • 장점: 오프라인/온라인에서 직접 소통하며 신뢰를 쌓고, 유료 프로젝트로 이어질 가능성 증가
  8. 고객과의 인터뷰 콘텐츠 제작
    • 성공 사례 기반 고객 인터뷰 (영상, 블로그, SNS 카드뉴스)
    • 효과: 신뢰성 있는 추천 자료 확보
  9. 고유 컨셉의 무료 이벤트
    • 예: "무료 홈페이지 진단 이벤트" / "30분 안에 해결하는 디자인 문제"
    • 운영 방법: SNS/이메일로 신청 받아 선정
    • 효과: 즉각적인 고객 참여 유도, 유료 서비스 전환 기회 제공
  10. 책이나 PDF 콘텐츠 발간
    • 주제: "초보자를 위한 노코딩 홈페이지 제작 가이드" / "홈페이지 제작 프로젝트의 숨겨진 꿀팁 10가지"
    • 목적: 콘텐츠 제작자로서의 권위와 전문성 강화, "신뢰할 만한 전문가"로 인식
