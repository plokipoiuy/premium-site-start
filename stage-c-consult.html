첫 상담 체크리스트 ⌄

고객이 "네"라고 답한 뒤 실제로 만나서(또는 통화로) 상담할 때 준비물과 말하는 순서입니다.

상담 전 준비

  • 상대방 인스타 / 홈페이지 미리 분석
  • AI로 만든 샘플 이미지 2~3개 준비
  • 기본 가격표 (3가지 옵션) 준비
  • 작업 기간 안내 준비 (예: 2주 완성)

상담 중 이 순서로 말하세요

  1. "지금 [업종] 하시면서 어떤 부분이 제일 불편하세요?" → 문제 파악
  2. "고객분들이 주로 어떻게 연락 주시나요?" → 현재 상황 파악
  3. "홈페이지가 생기면 어떻게 활용하고 싶으세요?" → 욕구 파악
  4. 샘플 보여주기 → "이런 느낌으로 만들어드릴 수 있어요"
  5. 가격 제안 → "지금은 포트폴리오 기간이라 [금액]으로 해드리고 있어요"

상담 후 24시간 안에

  • 미팅 내용 정리해서 카톡 or 이메일로 발송
  • 구체적 제안서 (1장 이내) 발송
  • 계약 날짜 잡기
첫 회신 스크립트 (질문 4개) ⌄

문의가 들어오면 바로 견적을 던지지 말고, 아래 4가지 질문으로 먼저 회신하세요.

첫 회신 메시지
안녕하세요, 연락 주셔서 감사합니다.
정확한 견적을 위해 4가지만 확인 부탁드려요.

1. 홈페이지로 가장 얻고 싶은 결과는 무엇인가요? (예약 / 문의 / 소개)
2. 언제까지 필요하신가요?
3. 생각하신 예산 범위가 있으실까요?
4. 사진·로고·소개글 자료는 준비되어 있나요?

답변 주시면 24시간 안에 제안서 보내드리겠습니다.

첫 회신에서 바로 금액을 던지면 비교 대상이 되고, 질문을 먼저 하면 전문가가 됩니다.

현재 사이트 문제점 진단 ⌄

고객에게 기존 홈페이지가 있다면, 무엇이 문제인지 정리하는 단계입니다. 이 단계는 강의 자료에 별도의 프롬프트나 스크립트가 없습니다 — "전광판" 도구의 진단 섹션에 직접 자유롭게 정리해서 입력하면 됩니다.

전광판 01 · 문제점 진단
레퍼런스 비교분석 프롬프트 3단계 ⌄

AI에게 아래 프롬프트를 수정해서 단계별로 입력합니다.

전광판 02 · 비교 분석
1단계 · 레퍼런스 심층 분석
1단계: 당신은 UI/UX 분석 전문가입니다. 제시된 [레퍼런스 사이트]를 분석하여 초보 기획자가 참고할 수 있는 리포트를 작성해 주세요.

[분석할 사이트: URL 또는 서비스명 입력]

다음 5가지 항목에 맞춰 상세히 분석해 주세요:
1. 전략(Strategy): 이 사이트가 해결하려는 사용자의 문제와 핵심 타겟은 누구인가?
2. 구조(Structure): 메뉴 구성과 페이지 전환 흐름이 얼마나 직관적인가?
3. 레이아웃(Layout): 시선 유도를 위해 콘텐츠를 어떻게 배치했는가? (섹션 구성 등)
4. 비주얼(Visual): 브랜드 이미지를 구축하는 컬러, 폰트, 이미지 스타일의 특징은?
5. 경험(Experience): 사용자의 행동을 유도하는 버튼(CTA)과 인터랙션의 특징은?

결론적으로, 이 사이트에서 반드시 벤치마킹해야 할 '성공 공식' 3가지를 정리해 주세요.
2단계 · 내 기획안으로 치환
2단계: 위의 분석 결과 중에서 [내가 특히 마음에 든 요소 1~2개]를 반영하여, 내가 만들고자 하는 [내 홈페이지 주제]에 적용해 보려 합니다.

[내 홈페이지 주제 및 정보: 예 - 1인 출판사 홈페이지 (내용입력)]
[참고하고 싶은 요소: 예 - 토스의 깔끔한 여백과 대화체 문구 (내용입력)]

다음 질문에 답변하며 내 홈페이지의 기획 초안을 잡아주세요:
1. 레퍼런스의 장점을 내 주제에 어떻게 변형하여 적용할 수 있을까?
2. 내 타겟 고객에게 맞춘 핵심 헤드라인(문구) 제안
3. 메인 페이지에 반드시 들어가야 할 5개 섹션 구성 (위에서 아래 순서로)
4. 사용자가 마지막에 꼭 클릭해야 할 버튼(CTA)의 문구와 위치 제안
3단계 · 디자인 및 제작 가이드
3단계: 2단계에서 기획한 내용을 바탕으로, 실제 제작을 위한 구체적인 '디자인 및 설계 가이드'를 작성해 주세요.

내용에 포함될 사항:
1. 컬러 팔레트: 메인 컬러, 보조 컬러, 배경색의 HEX 코드 제안 (레퍼런스 느낌 유지)
2. 타이포그래피: 제목과 본문에 어울리는 폰트 스타일과 크기 제안
3. 섹션별 상세 설명: 각 섹션에 들어갈 이미지의 느낌과 텍스트 배치 상세 기술
4. 제작 팁: 초보자가 이 디자인을 구현할 때 가장 주의해야 할 디테일(여백, 정렬 등)

마지막으로, 이 기획대로 홈페이지를 만들기 위해 AI(Cursor, 클로드 등)에게 입력할 수 있는 '최종 프롬프트 요약'을 작성해 주세요.
사이트맵·콘텐츠 기획 프롬프트 2단계 ⌄

위에서 받은 설문 내용을 챗지피티에게 입력해 사이트맵을 기획합니다. 참고 이미지는 첨부하고, 프롬프트는 복사 및 수정 후 사용하세요.

전광판 03 · 기획
1단계 · 사이트맵 프롬프트
홈페이지 제작 전문가 입장에서 기획을 도와줘. 웹빌더로 만들 홈페이지의 사이트맵을 만들어줘. 아래는 고객에게 받은 홈페이지 관련 사전질문 내용이야. 레퍼런스 페이지는 캡쳐로 첨부할게. 아래 형식에 맞게 답변해줘.

[사이트맵 형식]
1. 사이트 메뉴(필요한 경우 서브메뉴, 메뉴 갯수와 명칭은 최소로 간결하게)
2. 첫번째 메뉴 안의 페이지 구성 섹션(히어로, 서비스 소개, 브랜드 소개, 후기, CTA 등)
3. 나머지 메뉴 동일
4. 추가 제안

예시 결과 보기

감성 빈티지 소품샵 홈페이지 기획안

1. 사이트 메뉴 (최소·간결 구조)

  • 홈(Home)
  • 상품(Shop) — 신상품(New), 베스트(Best)
  • 브랜드 소개(About)
  • 고객 후기(Review)
  • 문의/안내(Contact)

메뉴는 5개, 고객의 주요 행동(쇼핑 → 신뢰 → 문의) 중심으로 단순화.

2. 홈(Home) 페이지 섹션

  • 히어로 배너: 대표 소품 이미지 + 브랜드 메시지 + CTA("지금 쇼핑하기")
  • 베스트/신상품 하이라이트: 4~6개 대표 아이템 카드형 배치
  • 브랜드 스토리 티저: "오래된 것에서 새로움을 찾다" 한 줄 스토리 + '더 알아보기' 버튼
  • 고객 후기 티저: 별점/사진 포함 2~3개 인용문
  • 이벤트/프로모션 영역: 시즌별 할인·무료배송 안내
  • 최종 CTA: "지금 바로 쇼핑 시작하기" 버튼

3. 상품(Shop) 페이지 섹션

  • 카테고리 필터: 인테리어 소품 / 문구 / 주방 / 패브릭 등
  • 상품 카드형 그리드: 썸네일, 이름, 가격, 장바구니 버튼
  • 정렬 옵션: 신상품 / 인기순 / 가격순
  • 추천 배너: "빈티지 감성 데일리 아이템" 테마별 큐레이션

4. 브랜드 소개(About) 페이지 섹션

  • 스토리 히어로 이미지: 따뜻한 매장/소품 사진 + 문구 "시간이 머무는 소품"
  • 브랜드 철학: 감성, 빈티지, 지속 가능한 소비에 대한 이야기
  • 창업자 소개: 브랜드 시작 계기 + 제작/큐레이션 과정
  • 매장/공방 사진: 공간과 분위기 강조

5. 고객 후기(Review) 페이지 섹션

  • 별점/평점 요약: 전체 평균 별점, 후기 건수
  • 고객 사진 리뷰: 실제 공간에서 사용한 사진 + 짧은 코멘트
  • SNS 연동: 인스타그램 태그(@브랜드명) 게시물 자동 노출
  • 리뷰 CTA: "나의 소품 후기를 남겨주세요"

6. 문의/안내(Contact) 페이지 섹션

  • FAQ: 배송/교환/환불 정책 간단 정리
  • 문의 폼: 이름, 이메일, 문의 내용, 파일 업로드(선택)
  • 고객센터 정보: 이메일, 카카오톡 채널, 전화번호
  • 매장 위치 지도(선택): 오프라인 스토어 있을 경우

7. 추가 제안

  • 리드 마케팅: "회원가입 시 10% 할인 쿠폰 제공" 팝업 → 이메일 확보
  • 프로모션 배너: 시즌별 이벤트, 기프트 패키지 강조
  • 스토리텔링 콘텐츠: 블로그/뉴스 메뉴 대신, About에 브랜드 이야기·소품의 히스토리 연재
  • SEO 키워드: "빈티지 소품샵, 감성 인테리어 소품, 아날로그 소품"
  • 리뷰 강화: 구매 후 리뷰 작성 시 포인트/쿠폰 지급
2단계 · 콘텐츠 작성 프롬프트
확정된 사이트맵 내용을 바탕으로 구체적인 콘텐츠 내용을 작성해줘. 한 페이지씩 확정된 내용을 작성하면 해당 페이지에 대한 구체적인 내용을 작성해줘.

[콘텐츠 형식]
1. 해당 섹션 구성 요소:(소제목, 설명, 이미지, 영상, 갤러리, 입력폼, 버튼 등 필요한 요소)
2. 구체적인 내용(소제목 및 설명의 최대한 간결하고 구체적인 카피라이팅, 이미지 혹은 영상의 내용 설명)

[확정된 사이트맵 내용]
-(메뉴1 확정된 기획 내용)
예시 결과 보기 — 홈(Home) 페이지 콘텐츠 기획안

1) 히어로 배너

구성 요소: 소제목 / 설명 문구 / 대표 이미지(또는 영상 배경) / CTA 버튼

  • 소제목(헤드라인): "일상에 빈티지를 더하다"
  • 설명 문구: "시간의 흔적이 담긴 감성 소품, 당신의 공간을 특별하게 만듭니다."
  • 이미지: 우드 테이블 위에 빈티지 조명, 책, 작은 소품들이 놓인 따뜻한 분위기의 연출 컷
  • CTA 버튼: "지금 쇼핑하기 →"

2) 베스트/신상품 하이라이트

구성 요소: 소제목 / 상품 카드(대표 이미지, 상품명, 가격) / 더 보기 버튼

  • 소제목: "가장 사랑받는 아이템"
  • 설명: "많은 분들이 선택한 베스트셀러와 이번 시즌 신상품을 만나보세요."
  • 이미지: 상품 4~6개 카드형 (예: 빈티지 시계, 에나멜 머그컵, 우드 캔들홀더, 패브릭 쿠션)
  • 버튼: "전체 상품 보러가기 →"

3) 브랜드 스토리 티저

구성 요소: 소제목 / 짧은 설명 문구 / 이미지(스토리와 어울리는 감성 컷) / 버튼

  • 소제목: "오래된 것에서 새로움을 찾다"
  • 설명: "빈티지의 가치와 감성을 현대적인 라이프스타일 속에 담았습니다."
  • 이미지: 작은 공방 또는 창가에 진열된 소품들의 감성 컷
  • 버튼: "브랜드 이야기 더 보기 →"

4) 고객 후기 티저

구성 요소: 소제목 / 후기 인용구 2~3개 / 고객 사진(제품 사용 장면) / 별점

  • 소제목: "고객이 전하는 진짜 이야기"
  • 후기 예시: "공간이 확 달라졌어요. 따뜻한 분위기가 마음에 들어요." (★★★★★) / "작지만 확실히 특별한 존재감을 주네요." (★★★★☆)
  • 이미지: 고객이 실제 집안/책상 위에 소품을 두고 찍은 생활컷

5) 이벤트/프로모션 영역

구성 요소: 소제목 / 설명 문구 / 배너 이미지 / 버튼

  • 소제목: "가을 시즌 특별 이벤트"
  • 설명: "10월 한정, 전 상품 무료배송 & 신규 회원 10% 할인 쿠폰 증정"
  • 이미지: 시즌 무드(가을 감성 소품, 브라운·오렌지 톤 배경)
  • 버튼: "이벤트 확인하기 →"

6) 최종 CTA

구성 요소: 소제목 / 설명 문구 / CTA 버튼

  • 소제목: "지금 바로 시작하세요"
  • 설명: "당신의 공간을 채울 단 하나의 빈티지 소품을 만나보세요."
  • 버튼: "지금 쇼핑 시작하기 →"

견적서 기본 항목

견적 산정 기준 안내문
금액은 난이도, 분량, 전문성 등 다양한 요소에 의해 큰 차이가 있습니다.
표기된 금액은 예시이며 더 낮거 더 높은 비용인 경우도 많으니 참고용으로만 활용해주세요.
모든 경우의 수를 반영할 수 없어 최소한의 전문성, 초급~중급 정도의 난이도 기준임을 말씀드립니다.
상황에 따라 0원으로 포함되는 항목이 될수도, 10배 이상 받는 서비스가 될 수도 있습니다.

추가 꿀팁
· 상한 하한 설정: 예산을 아끼고 싶은 고객에게는 하한가, 만족도 높은 서비스를 한 번에 원하는 고객에게는 상한가를 제시할 수 있습니다 (제공 범위는 달라집니다).
· 계약금: 후불은 정산 리스크가 있습니다. 가치입증·브랜드 힘이 쌓일수록 선불로 전환하세요. 100만원 이상 고액 프로젝트는 계약금+잔금, 기간이 길면 계약금·중도금·잔금 3단계로 나누기도 합니다.
· 항목의 구체화: 항목을 세세히 쓰면 많은 서비스를 받는 느낌을 주지만 그만큼 이행 의무도 커집니다. 포괄적으로 쓰면 리스크는 줄지만 금액 설득력이 떨어질 수 있으니, 상황에 맞게 구성하고 구두로 보강하세요.

계약서 작성 및 발송 ⌄

견적이 확정되면 계약서를 작성해 발송합니다. 아래 항목들을 빠짐없이 포함하세요.

계약서 필수 항목 (10가지)

  1. 계약 당사자 정보 — 서비스 제공자/클라이언트의 이름(회사명), 주소, 연락처, 사업자등록번호(필요 시)
  2. 계약의 목적 및 범위 — 예: "홈페이지 제작 및 유지보수 서비스 제공"
  3. 서비스 상세 내역 — 작업 항목, 작업 범위, 산출물 종류 (디자인 파일, 퍼블리싱 완료본, 유지보수 내용 등)
  4. 작업 일정 — 주요 이벤트 및 납기일 명시 (예: "1차 시안 제출: YYYY-MM-DD")
  5. 대금 및 결제 조건 — 총 금액, 지급 방식, 분할 지급 여부 (예: 계약금 30%, 중간 40%, 최종 30%)
  6. 수정 및 변경 조건 — 기본 포함 수정 횟수와 초과 시 추가 비용 (예: "수정 2회 포함, 이후 1회당 50,000원 추가")
  7. 계약 해지 및 환불 조건 — 진행 단계별 환불 정책 (예: "기획 완료 후 해지 시 계약금 반환 불가")
  8. 지적재산권 및 사용 권한 — 예: "최종 작업물의 저작권은 대금 전액 지급 후 클라이언트에게 이전"
  9. 비밀유지 조항 — 예: "계약 종료 후에도 1년간 비밀 유지"
  10. 책임 소재 — 예: "클라이언트의 자료 지연 제공으로 발생한 일정 지연은 제공자의 책임이 아님"

클라이언트의 만족도를 높이는 항목

  1. 서비스 품질 보장 — 요구사항에 부합하며, 미흡한 경우 재수정 진행
  2. 사후 지원 — 계약 종료 후 일정 기간 무료 유지보수 (예: "종료 후 30일간 기본 오류 수정 무료")
  3. 정확한 일정 보장 — 주요 단계 준수, 지연 시 사전 통보
  4. 기술적 지원 문서 제공 — 사용 가이드/참고 문서 제공 (예: "홈페이지 관리 매뉴얼 PDF 제공")

스스로를 보호하는 항목

  1. 수정 요청 범위 제한 — 기본 포함 횟수와 추가 비용 명확히 명시
  2. 자료 지연 및 책임 분리 — 클라이언트 자료 지연 시 면책 조항
  3. 불가항력 조항 — 자연재해·질병 등 예외 상황 책임 면제
  4. 저작권 보호 — 최종 대금 지급 후에만 저작권 이전 명시
  5. 계약 해지 시 보상 조항 — 작업 단계에 따라 정산된 금액 반환 기준 명시

작성 시 유의사항

  1. 명확하고 구체적인 표현 사용 — 숫자와 기간을 명확히 (예: "수정은 3회까지만 포함, 초과 시 추가 비용 발생")
  2. 법률 검토 — 작성 전 전문가(법률 자문, 변호사 등) 검토로 법적 효력 확인
  3. 상호 서명 필수 — 계약 당사자 모두 서명해야 효력 발생
  4. 전자 문서 사용 권장 — 전자 계약 플랫폼(예: 모두싸인) 활용
  5. 공정성 유지 — 한쪽에 지나치게 유리한 조건이 아닌, 양쪽 모두 동의할 수 있는 항목 설정
네이버 엑스퍼트 (법률 자문 검색) 모두싸인 (전자 계약)

모두싸인으로 계약서 작성 및 발송하기

  1. 모두싸인 가입 및 로그인
  2. 좌측하단 '서식 검색'
  3. '웹사이트' 검색
  4. 결과 클릭 후 '서식 사용하기'
  5. '동의하기'
  6. 내용 작성 및 '저장하기'
  7. '작성 서식함'
  8. 서명 요청
  9. 서명자 정보 입력(한 명인 경우 두 번째 서명자는 'x' 클릭으로 삭제)
  10. '다음 단계로' 및 '전송하기'
