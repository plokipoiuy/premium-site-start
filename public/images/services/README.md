# 서비스 카드 이미지

`청소서비스` 섹션의 4개 카드가 아래 파일명을 그대로 불러옵니다.
같은 이름으로 이미지를 이 폴더에 업로드하면 코드 수정 없이 바로 적용됩니다.

| 파일명 | 서비스 |
|---|---|
| `move-in.jpg` | 입주청소 |
| `move-out.jpg` | 이사청소 |
| `residential.jpg` | 거주청소 |
| `partial.jpg` | 부분·집중청소 |

권장: 4:3 비율, 가로 1200px 이상, 300KB 이하(용량이 크면 로딩이 느려집니다).
파일 확장자를 `.jpg`가 아닌 다른 형식(`.png`, `.webp` 등)으로 올리는 경우
`lib/data/services.ts`의 `image` 경로도 함께 확장자를 맞춰줘야 합니다.
